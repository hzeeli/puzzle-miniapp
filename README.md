# 一拼成画

微信原生休闲小游戏，采用生活照片连块玩法。拖动单片或已接合的一组交换位置，拼成完整照片后消除、下落并补牌。

- 10个固定版本关卡；前三关教学，后七关均8张照片，以排布、连接与补牌依赖递进。
- 原创生活照片、雾蓝与奶油蜜金界面、连续拖拽与翻牌、音效和震动开关。
- 本地续玩与最佳用时；微信云端逐步校验通关、服务器计时和每关前10榜单。
- 通过微信官方用户信息按钮和CloudID核验头像昵称；拒绝授权可继续本地游玩。
- 断网成绩独立保留，支持重试；提供个人数据删除与过期挑战清理。

## 开发与运行

```sh
npm ci
npm test
npm run check:levels
npm run build
```

在微信开发者工具中导入项目根目录，入口为 `game/game.js`。工程AppID与云环境已按「一拼成画」配置。源码修改后先构建再编译。

浏览器仅用于界面和规则验收，微信身份与云功能应在开发者工具或微信客户端验证：

```sh
npm run serve -- 4174
```

## 目录

| 路径 | 内容 |
|---|---|
| `game/src` | Canvas客户端、交互和平台适配 |
| `game/assets` | 运行时照片、界面素材与声音 |
| `shared` | 唯一规则源、固定关卡和资料策略 |
| `cloudfunctions/gameApi` | 可信身份、通关校验、成绩和排行榜 |
| `cloudfunctions/maintenance` | 定时清理七天前挑战记录 |
| `art/platform` | 平台应用图标，不占小游戏运行包 |
| `tests` | 规则、客户端生命周期、六尺寸UI与云端测试 |

构建会同步共享规则至云函数目录，生成浏览器验收包；这些派生目录不要手工修改。
