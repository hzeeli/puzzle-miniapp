# 一拼成画 · 绘本花园

微信原生 Canvas 2D 拼图小游戏。拖动一片照片或整组已连好的碎片，拼成完整画面，腾出位置让下一批照片落下。

- 首页显示当前关号。主线首次编排 100 关，通关后直接进入下一关，第 101 关起延续后段难度带。
- 108 张照片分布在主包与八个微信分包。每关使用不同题材的照片，并与前七关错开。
- 闯关榜按服务器验证的连续通关数排名，同关按云端先达成排序。操作记录在本地保存，联网后按关号补交，可以通过榜单补验只有历史成绩的旧局。
- 保留本关原图、提示、花园工具、头像授权和个人设置。

## 运行

在项目根目录执行以下命令。微信开发者工具导入本目录，入口为 `game/game.js`。

```sh
npm ci
npm run build
npm run check:levels
npm test
```

浏览器验收可执行 `npm run serve -- 4174`。头像授权、云端身份与微信分包需在开发者工具或手机微信验证。

## 源码与资料

| 路径 | 内容 |
|---|---|
| `game/src` | Canvas 画面、输入、音效、闯关进度与平台接口 |
| `shared` | 版本化棋局规则、固定关卡、确定性生成、旅程与图册元数据 |
| `game/assets`、`game/packs` | 首包美术、声音及八个照片资源包 |
| `cloudfunctions` | 主线闯关榜、玩家档案、旧版接口与历史挑战清理 |
| `tests` | 规则重放、存档兼容、客户端、云端及多屏几何检查 |
