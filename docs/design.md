# 绘本花园 · 连续闯关

打开游戏可开始当前关或续玩。准备页展示这关的照片、首次遇到的机制和三星目标；通关结算直接进入下一关。首页的其他入口是闯关榜和个人设置。每局仍能查看原图、请求提示和使用花园工具。

[百关设计及逐关验证](百关设计.md)记录一期编排与后续出题方法。照片保留原色，水彩插画退到棋盘边缘。每关的照片来自不同题材，沿主线推进时避开最近七关的图片。

闯关榜依据服务器认可的连续通关数排名。每次完成的操作保存在本机，已开启云端功能的玩家联网后可同步。旧版本只有本地星数和用时的关卡保留本地成绩，可从榜单重新通关补验。补验使用独立存档，可以随时回到原有的主线半局。
