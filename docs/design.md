# 一拼成画：产品与美术规范

## 体验目标

玩家拖动照片碎片或已接合的一组。相邻位置正确时，内部接缝消失；完整照片短暂停留，随后收集并补入新的碎片。照片恢复与连续操作构成主要奖励。

面向喜欢图片解谜、短时放松的玩家，不预设性别或年龄偏好。10关均可选择；每关记录个人用时，可主动开启微信云成绩和本关前十榜。

## 设计依据

用户视频是交换、连块、消除与落牌的直接依据。Jigsolitaire 的开发者展示用于比较照片主体尺度、克制HUD与接缝变化；Jigsaw Flow 官方素材用于比较多图混排的色块和构图；Jigsort 用于比较局部图像线索与功能分区。Scenario 的 Glazeline、Reeflume、Jiggle Jars 用于检查材质、光照、状态层级与连续反馈。

研究中的宣传图不视为真实操作证据；第三方图片不进入游戏包。研究记录与图源保存在工作目录。

## 视觉生产方式

先生成完整游戏目标截图，确定照片占比、材质和配色；再据此派生独立素材、实现可玩的代表性切片。目标图不能替代微信运行验收。已确定以用户选择的雾蓝与奶油蜜金目标图为统一视觉基准；首页、选关、准备、结算、排行榜、设置先完成完整目标画面，再进行资产派生和真实装配。

核心照片使用原图精确裁切，保持2:3比例，不能直接照搬生成稿重新想象的象限。棋盘优先使用可用宽度；短屏按高度缩放，微信胶囊和底部安全区不可遮挡。

静止牌、拖起组、可落目标、已接组、完整图、空位和牌背应有明确的状态差异。相连组共享外轮廓，内部边、圆角和阴影随接缝一起消失。拖起与释放保持指尖位置连续，目标被拆开的片按真实位移移动。

文字只承担关卡、用时、必要计数与操作。教学用就地手势和目标轮廓，完成用整图展示。隐私和错误信息仅在用户需要作决定时出现。

## 素材职责

| 元素 | 正式素材 | 程序承担部分 |
|---|---|---|
| 照片碎片与成图 | 原创生活照片，检查四象限辨识度 | 精确裁切、连接轮廓、位移和收集 |
| 牌背与牌堆 | 按目标图派生的统一正视牌背 | 真实库存、叠放、下落和翻面 |
| 功能控件 | 同一光照和材质的透明图形素材 | 点击区域、按压与禁用状态 |
| 教学手势 | 透明指示手素材 | 真实可行路径、出现与退场 |
| 底面 | 安静的低频材质与光照 | 覆盖不同画布比例 |
| 系统信息 | 不烘焙变化数字 | 真实关卡、耗时和进度 |
| 接合与完成 | 真实照片与匹配的短促高光 | 接缝消失、展示、收集、补牌时序 |

照片选择依据大主体、局部轮廓、颜色差异。初级关卡使用明显不同的图像；相近题材在后续关卡中有意安排。素材数量、模型名称和文件体积不作为美术合格证据。

## 代表性切片验收

1. 照片、空位、牌背和已接组直接可辨，框体和文案不遮挡图像。
2. 拾起、释放、交换和目标拆分连续，无跳回原格。
3. 内部接缝真正消失；吸附、短音和触觉响应同一事件。
4. 玩家先看清完整照片，再收集；辅助效果不覆盖主体。
5. 清除、下落、牌背入场、翻面的顺序清楚。
6. 多图完成互不遮挡，全部效果保持在屏内。
7. 在390×844、375×667及微信真实画布核对布局、触点和材质，随后真机回归。

功能测试、美术走查与真实设备体验分别记录，任何一项不能代替另一项。

## 用户与成绩

原生微信小游戏Canvas 2D，wx.cloud连接云函数。可信身份来自云端微信上下文，客户端不能指定OpenID或直接写成绩。每关固定版本，服务端复放操作并按服务器起止时间记分；排名计时包含暂停、后台与网络传输。

每用户每关一条个人最佳，前十榜稳定排序，只返回公开昵称、已授权的微信头像与成绩；未授权时使用中性占位头像。未完成局面保存于本机，云端保存通关成绩；待上传终局独立持久化，弱网可继续本地游玩。用户可删除个人云档案与成绩。

players、runs、bestScores客户端权限为ADMINONLY。维护函数每日清理七天前的挑战记录，个人最佳不随之清除。身份、重放、事务幂等与并发删除需要真实环境验证。
