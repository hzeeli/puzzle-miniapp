# 拾光冲印室的十二关

棋盘有 4×4 格，每张照片由左上、右上、左下、右下四个象限组成。拖动一片会带走所有已经与它正确接合的相纸。被覆盖的碎片沿平移方向回填空位，所以玩家可以搬移整组，也可以用一小片拆开目标组。一张照片拼为完整的 2×2 后归档，剩余连块按刚体下落，从各自列的胶卷补片。

## 可重建的本地新局

`shared/generate-level.js` 接受 `{generatorVersion, templateId, seed, photoPool}`。照片池可传任意不重复的字符串 ID，至少应有该模板要求的图数。也可用有序的 `photoIds` 替代照片池，直接指定本局照片。调用方可据此落实跨关去重、近期回避或内容更新。池按稳定顺序无放回抽样，选片与发盘各用独立随机序列。

玩法从模板出发做 3–7 次可逆交换。每个候选落点都经过正反两次规则确认，显影、归档或改动定位钉的候选会被剔除。候选不足时取最后一个已验证局面。沿这些交换的逆序回到模板，再走其参考解，就是新局的一条完整路线。将新增交换数计入参考步数和星级门槛。每列库存和图钉框架沿用模板，后续自由操作沿用同一套规则。

存档保留 `generatorVersion`、`templateId`、规范化后的 `seed`、当次有序的 `photoIds` 和操作列表。即使在线内容池随后更新，仍可本地重建关卡并逐步重放。生成器版本与固定关卡规则版本分别维护。测试对十二个模板各生成十二张不同开局，核对同种重建、照片去重、钉位约束以及随机操作后的提示恢复。

## 显影和定位钉

暗片可以移动，显影前以单片参与交换和下落。拿起暗片交换会主动显影。一次交换形成新的接边时，新边两端正交相邻的暗片也会显影。整图归档前，紧邻整图的暗片一并曝光。显影立即参与同一次操作的接合检查，所以顺带显影能在同一步中完成额外照片。

图钉锁定相纸的位置。源连块含钉、或目标区域覆盖钉格时整步无效。其他片能与钉片接合，接合后整块停止下落。完成该张照片会在归档事件中释放图钉。每枚钉所属的四片均在初始棋盘上，其象限与钉位唯一决定一个能放下整图的 2×2 区域。双钉章节的两个区域互不重叠。

## 可继续完成的依据

一张图的库存只存在于一列并连续排列。该列最前一张可有部分碎片在桌上，此后每张都以完整四片入队。若有库存的列数为 q，补片后桌上至少有 4q 片。如果没有一张未完成的照片在桌上齐片，每列库存对应的照片在桌上至多有 3 片，全盘最多 3q 片，产生矛盾。无库存时，每张未完成照片的四片都已在桌上。

对于带钉的照片，其已连上的所有同图碎片都在钉位所定义的正确位置，其余同图连块可平移至同一相框。相框内部不含其他钉，该图已对齐的象限与未对齐象限也互不重叠。主动显影可以处理碰巧已经落在正确象限但仍未曝光的碎片。每次主动显影至少减少一张暗片；一旦曝光，恢复同样的组装过程。自动下落仅在完成照片后触发，每次触发都减少剩余照片数。

提示器枚举齐片照片及合法锚点，试走完整局部计划，优先释放图钉，再比较到下一次成图的步数和剩余接合质量。常规目标每次至少对齐一片。候选组装计划暂时不能产生成图且仍有暗片时，改为直接揭开一张暗片。参考解记录在测试目录，线上运行包只携带关卡和评分阈值。

## 共享接口及验收

- `getLevel(id, version=4)` 返回对应版本的固定关卡。历史十关保存在 `shared/levels-v3.json`，历史完整轨迹可继续复放。
- `createState(level)` 校验库存守恒和图钉相框，生成含 `hidden`、`pinned` 的独立局面。二者记录本关 token 编号。
- `groups(board, hidden)` 和 `joined(board, a, b, hidden)` 排除暗片接合。
- `moveReason(state, from, to)` 返回合法结果 null，钉住时为 `PINNED_BLOCKED`。与 `applyMove` 共用平移和落点判定。
- `applyMove` 生成独立前后快照。曝光事件为 `reveal.tokens`，归档事件给出 `complete.photoIndices` 与 `complete.unpinnedTokens`。归档后可能触发 `fall`、`refill` 和下一次归档。
- `replay(level, moves)` 从固定开局按顺序重放每一步；云端对每条轨迹保留原有的 2,000 步长度上限。
- `starsFor(level, moveCount)` 计算已完成局数的步数星级。

用 `node scripts/generate-levels.cjs` 从固定种子重新生成，用 `npm run check:levels` 只读核对，用 `node --test tests/rules.test.cjs tests/levels.test.cjs` 执行以下检查。

- [x] 十二关完整解、评分与每次动画事件的牌张守恒。
- [x] 十个历史关卡原有轨迹逐关重放。
- [x] 四列库存前缀计数条件、144 组随机扰动后继续求解。
- [x] 主动及邻接显影、暗片隔离、钉位阻挡与释放、重力和双钉相框。
