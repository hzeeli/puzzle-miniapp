## 0. 设计定调：为什么是「清透绘本花园」+ 108 图长线日常

1. **彻底否决深色棱角暗房**：旧版墨绿暗布 + 30% 黑幕 + 直角/小圆角硬框（`r=1~5px`）+ 宋体衬线，压抑严肃、缺乏日常轻松打开玩一局的愉悦感。
2. **明确划清“明亮休闲”的审美边界（不走玩具/糖果/廉价油腻风）**：
   - 我们直接观察了市售 7 款头部明亮休闲游戏（Royal Match、Candy Crush、Jigsawscapes、Jigsawcard、Puzzle Villa、Tile Explorer、Homescapes、Wordscapes）的 25 张官方商店截图（全部存档于 `outputs/明亮新版/设计参考/`），**只吸收它们“高明度通透构图、大圆角友好交互、一眼看懂层级、轻快每日回访”的成熟骨架**；

3. **基于现有 60 站 + 每日 + 自由 + 108 照片（前 108 位无重复）的深度升级**：
   - 当前代码仓已搭好 `shared/journey.js`（60 站 / 每日 / 自由 / 108 图防重轮盘）、`shared/generate-level.js`（可逆交换数学无死局）、`game/src/photo-path.js` 与 `game/game.json`（主包 + `album-02`~`album-09` 共 9 卷分包）；

## 2. 锁定美术规范：「清透绘本花园 · Translucent Storybook Garden」

### 2.1 以 `game/assets/ui/garden.jpg` 为母本的视觉黄金法则

仔细拆解已生成的母图 `game/assets/ui/garden.jpg`，我们的全站美术必须与其 100% 融为一体，像同一位绘本水彩画师亲手画出的完整作品：

1. **视觉焦距三层分工（照片永远最突出！）**：
   - **L0 绘本花园环境层（柔和、高明度、低对比）**：清透水彩蓝天（顶部）+ 淡薄荷绿玻璃花房与远山（左中远景）+ 大面积柔和低饱和浅绿草坪留白（中央舞台区）+ 珊瑚虞美人/小白雏菊/蓝勿忘我石板小径（底角边缘装饰）。水彩笔触温润柔和，**整体低对比、零杂乱高频纹理**。
   - **L1 写实照片主角层（100% 清晰、高鲜活、雪白纸边）**：无论在首页花房展架、中局 4×4 棋盘，还是图鉴与结算页，**真实生活摄影照片永远是画面里唯一锐利、高对比、色彩最鲜活的绝对焦点**！照片外框使用纯净暖白棉纸边（`#FFFDF9`）与极克制的暖灰绿投影，瞬间从柔和水彩草坪中“浮”出来。
   - **L2 手绘水彩棉纸 UI 层（清透、大圆角、轻盈透气）**：所有按钮、胶囊、弹窗均表现为“放在花园里的高级水彩棉纸卡片与手绘彩釉/亚麻大圆角钮”——**大圆角、微透明透气感、温润手绘浅边、柔和低饱和水彩过渡**，绝不做反光塑料/硬橡胶/厚黑描边/深色暗幕。

### 2.3 大圆角、手绘笔触与字体规范
- **全站大圆角体系**：弹窗卡 `r = 26px`；主按钮全圆枕形 `r = 26~28px`（高度 `54~58px`，底部柔和厚度仅 `3~4px`，内缩 `1.5px` 半透明暖白细边模拟绘本水彩纸缘）；HUD 胶囊全圆 `r = h/2`；选关/图鉴卡 `r = 16px`（内图 `r = 11px`）；棋盘底托 `r = 18px`，照片散片与连块外轮廓 `r = 10px`（`2.5px` 纯白相纸边，接合后内缝与内圆角完全消失）。
- **字体**：彻底移除宋体，全站采用圆润清晰的无衬线字栈 `-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`；标题 `700~800` 适度字距，配极柔和的暖白光晕或淡松针投影，绝不加粗黑硬描边；计时器/步数严格等宽对齐。
- **核心玩法的「绘本花园」清透视觉化（100% 沿用 `shared/rules.js` 规则与引擎，仅重塑表现与文案）**：
  1. **晨雾云片（原 `hiddenTokens` 暗房底片）**：在未显影照片上覆一层**半透明清透水彩白雾纸膜（`rgba(244, 250, 252, 0.90)`）**，中央手绘一朵极轻柔的**浅天蓝小水彩云 + 微微飘动的小风叶**。主动拖动或在旁接合/成图时，白雾像**晨风吹散薄雾**一样径向消散，清晰明丽的照片瞬间绽放！
  2. **花扣定锚（原 `pinnedTokens` 黄铜钉）**：在被锁定的照片边角别一枚**柔和手绘「小雏菊暖金花扣」**（暖白瓷盘 + 柔和向日葵花蕊，边缘加一圈淡蜂蜜金水彩框线）。尝试拖动时轻轻弹性微晃 + 轻脆木扣声 + 柔和提示“这片戴着花扣，把同图其余三片拼到它身边吧”；整图拼成时花扣化作 5 片柔和白黄花瓣飘散释放！
  3. **四列补牌堆（原暗房胶卷）**：重塑为**四叠大圆角奶油棉纸明信片背**，背面印有淡薄荷绿手绘小叶脉/花房徽记，右下角清透晴蓝圆角小标显示剩余张数，补牌翻面如微风轻翻水彩明信片。
  4. **过关庆祝（去塑料彩纸）**：用柔和水彩花瓣（淡粉虞美人、小白雏菊、嫩绿小叶）随微风缓飘 + 三颗温润手绘暖金星依次弹性点亮 + 刚拼好的完整高清照片在清透奶油明信片卡正中呈现，治愈又开心！
