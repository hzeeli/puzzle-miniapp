### 1.2 为什么本轮判定「暂不通过」
实装目前处于**“外壳已换绘本花园，核心交互件与部分页面还留着旧暗房/工具风半成品”**的状态：
- **核心对局盘面**里，未翻开的显影膜与顶部四列补牌堆仍是生硬冰冷的“胶片齿孔 + 机械相机光圈”，且散片缺乏清晰雪白相纸边与衬垫层次；

## 三、本轮 Codex 必改的核心视觉阻断项（按优先级排序）

### 阻断项 1（P0 · 核心玩法主屏）：重塑棋盘「晨雾云片 / 明信片补牌堆 / 相纸白边底托 / 花扣辨识度」

- **对应问题截图**：`04-花园棋盘.jpg`、`06-主线首站棋盘.jpg`、`离屏/08-game.png`、`离屏/14-short-game.png`
- **审美问题诊断**：
  1. **显影膜仍是冷硬胶片**：两边排列着黑色/冷蓝电影胶片齿孔，中间是机械相机光圈图标，放在清透水彩花园里极度违和，是旧版暗房最刺眼的残留。
  2. **四列补牌堆仍是工业取景框**：4 个扁平浅绿条框里画着相机取景框直角标 `[ ]` 与光圈符号，缺少绘本明信片的温润纸感。
  3. **棋盘底托偏薄、散片缺少雪白相纸边**：目前棋盘外围仅靠一条细线界定，内部未接合的散片几乎无白边分隔，导致相邻不同照片（尤其色彩接近的草地、木头）在视觉上粘连，不如 `绘本花园三屏示意.png` 中间屏与 `jigsawcard-01-play.jpg` 清爽利落。
  4. **花扣定锚偏小偏淡、首站引导线偏重**：锁定片左上角的扁平小黄星在橙色海星或金色烟花上极易融化难辨；首站引导虚线呈粗重暗绿测绘线风格，指向箭头不明显。
- **修改方向**：
  1. **显影膜 → 晨雾云片**：彻底删除电影胶片齿孔与相机光圈；改为高明度清透水彩白/淡晴蓝柔雾纸面（如 `#EFF8FD` → `#D9EEF9` 柔渐变），中央点缀轻盈柔和的手绘小白云与微风曲线/细小风叶。
  2. **补牌堆 → 奶油棉纸明信片叠**：彻底删除取景框直角线与相机光圈；改为暖奶油大圆角纸片叠（带柔和多层纸缘厚影），中心印极淡薄荷绿小叶/花纹，右侧用清透小圆章（如淡晴蓝/浅森绿圆点）承载剩余张数。
  3. **棋盘底托 + 清晰相纸白边**：给 4×4 棋盘增加半透明暖白棉纸底托（`rgba(255, 252, 245, 0.80)` + 温润浅绿柔边 + 轻环境影）；**独立散片与连块外缘统一加 `2~2.5px` 洁净雪白相纸描边与极轻浮影，已拼合连块内部严格零缝无内边**，一眼分清“断”与“连”。
  4. **花扣与引导线升级**：花扣改做**暖白瓷底圆章 + 暖金雏菊花扣**（尺寸略增大至约 22~26px，加清晰雪白外廓与轻影，锁定片框线为柔和暖金微辉）；首站新手引导线改为轻盈暖白/暖金柔光虚线弧 + 清晰圆润终点小箭头。
